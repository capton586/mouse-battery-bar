## 可以在自己的分支上扩展

- **USB 回报率（Hz）**：先对照厂家资料验证设备能报告哪些档位。用厂商软件改变一个档位，分别记录修改前后的读数和固件版本；有可靠对应关系后再实现读取或切换。操作系统收到移动事件的频率不能直接当作设备配置。
- **设置 DPI**：当前示例只读接收器报告的 DPI。建立设置功能时先确认可用档位，保留原值，对每次更新执行回读，再验证能恢复。
- **自定义按键**：先确定需求是 macOS 本地映射，还是写入鼠标的板载配置。这两者权限、持久性和撤销方式不同。只在需要它的鼠标分支中加入对应实现。

复测基础流程：从 DMG 拖到「应用程序」，开启／关闭登录项并在系统设置核对，按系统提示批准。若以另一 bundle ID 或签名重建，macOS 可能重新询问输入监控权限。
